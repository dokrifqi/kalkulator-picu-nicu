    📖Cara baca
    
      
      
        
    1. Kelompok usia
      1 sampai <3 th → tabel 1–2 th; 3 sampai <8 → 3–7 th; 8 sampai <16 → 8–16 th; 16–25 th. Usia <1 th belum ada rentang normal.
      2. 
        
    2. Tiap parameter
      Di bawah rentang = Turun, di atas = Naik, di dalam rentang (termasuk tepat di batas) = Normal.
      3. 
        
    3. Kesan per domain
      Dua parameter sama → kesan itu. Satu abnormal satu normal → ikut yang abnormal (keterangan dalam kurung). Arah berlawanan → tidak sinkron, cek ulang kurva/input.
      4. 
        
    4. Kualitas sinyal
      Angka hanya valid bila kurva Doppler tajam dan konsisten. BB/TB yang diinput ke alat dan tekanan darah memengaruhi SVI, CI, dan SVRI.
